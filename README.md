APOIO AO DIAGNÓSTICO DE CÂNCER DE MAMA (MALIGNO VS. BENIGNO) A PARTIR DE CARACTERÍSTICAS CELULARES DE EXAMES DE IMAGEM.
(Breast Cancer Wisconsin -Diagnostic- Data Set)


Avaliação Crítica de Modelos, Prevenção de Vazamento de Dados e Análise de Subgrupos — Base Breast Cancer Wisconsin (569 pacientes, 30 variáveis)

Pergunta Central do Projeto: "É possível classificar automaticamente se um tumor de mama é maligno ou benigno a partir de medidas morfológicas extraídas de exames de punção aspirativa por agulha fina (PAAF), minimizando ao máximo os falsos negativos na triagem clínica?" / “É possível classificar tumores mamários (Maligno vs. Benigno) a partir de medidas morfológicas minimizando falsos negativos na triagem clínica?”
